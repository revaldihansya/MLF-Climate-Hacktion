# MLF

Building an energy efficient society, one model at a time. 

## Our approach

Our dataset is a compilation of buildings and its characteristics. We use L1 regularization, linear regression models, as well as a genetic algorithm to efficiently decide which properties of a building could have its energy be reassessed and how much more efficient. 

## Setting up

Follow these instructions to set up the python notebook from your own local device!

### 1. Clone the repository

```bash
git clone https://github.com/revaldihansya/MLF-Climate-Hacktion.git
cd  MLF-Climate-Hacktion.git
```

### 2. Install the dependencies

```bash
pip install requirements.txt
```

### 3. Running the notebook

Now, you can run the notebook and each of its codecells at your own pace. Note: some cells may require some time to process, so consider the sample size carefully and allocate at least 3 hours for your code to run.

## Final Remarks

### Difficulties

This is our attempt at the Climate Hacktion 2026. We acknowledge the various limitations that we have within this project including:
* **Geographically and temporally mismatched:** This analysis is a proof of concept built on a North American proxy dataset (2018). The methodology is transferable even though the findings are not.
* **Time constraint of the Hackathon:** The time constraint of the hackathon prevented us from experimenting with different parameters and a larger sample size.

### Suggestions for future and dedicated projects

Following our attempt, future endevours should explore these suggestions:
* **Dedicated dataset:** To be able to focus on the pacific region of the world, where climates are very different, we should first compile a dataset within the region of target
* **Explore different models and parameters:** Our biggest problem with the short deadline was the inability to experiment with a wider range of parameters and exploring different models. Considering that will let us consider more possible results.
